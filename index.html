原题呈现与核心概念交互画板

先看懂原题条件，再动手拖动数轴上的两点体验“大的数 − 小的数”

20. 在数轴上，我们可以利用线段端点表示的两个数进行减法运算的方法，即大的数减去小的数，求线段的长度。 如图，在数轴上，点 A、B、C 表示的数分别是 −2、0、3， 线段 AB = 0 − (−2) = 2； 线段 BC = 3 − 0 = 3； 线段 AC = 3 − (−2) = 5。

📏 距离法则：大的数 − 小的数

数轴上右边的数总比左边大，任意两点间的距离就是右边的数减去左边的数。

线段长 = 右边的数 − 左边的数

🏃 动点规律：左减右加

动点向右运动坐标变大用加法，向左运动坐标变小用减法。

向右：起点 + 速度 × 时间  |  向左：起点 − 速度 × 时间
🖐️ 动手拖一拖：实时体验“大的数 − 小的数”
较大的数（右边） 0
较小的数（左边） −2
实时距离公式 0 − (−2) = 2

第（1）题 若点 E、F 表示的数分别是 −8 和 2，则线段 EF 的长为  。
作答区：
🎬 交互动画 1：跨原点距离合成演示（为什么 2 − (−8) = 2 + 8？）
演示进度： 合成总长 10

🎯 解题思路

先比大小：2 > −8。因为 E(−8) 在原点左边 8 格，F(2) 在原点右边 2 格，跨过原点合起来一共 8 + 2 = 10 格。用算式表示就是“减去一个负数等于加上它的相反数”。

✍️ 标准步骤

EF = 2 − (−8) = 2 + 8 = 10

第（2）题 点 M、N 为数轴上的两个动点，点 N 在点 M 的左边，点 M 表示的数是 −5，若线段 MN 的长为 12，则点 N 表示的数是  。
作答区：
🎬 交互动画 2：数轴定向向左平移演示（左减右加）
向左步数： 12.0 格
当前移动算式 −5 − 12 = −17
实时距离验算（大减小） −5 − (−17) = 12

🎯 解题思路

题目明确给出“点 N 在点 M 的左边”，说明 N 比 M 小，直接用口诀“左减右加”：从 −5 出发向左减 12。

✍️ 标准步骤

点 N 表示的数为：−5 − 12 = −17

验算：MN = −5 − (−17) = −5 + 17 = 12（完全符合题意）

第（3）题背景 点 P、Q 为数轴上的两个动点，动点 P 从点 A(−2) 出发，以每秒 2 个单位长度的速度沿 A−C−A 运动； 动点 Q 从点 C(3) 出发，以每秒 1 个单位长度的速度沿数轴向终点 A(−2) 运动。 设点 P、Q 的运动时间为 t（t > 0）秒。

第（3）①题 当点 P 沿 A−C 运动时，求点 P、Q 相遇时 t 的值。
作答区：
🎬 交互动画 3：相向相遇动态模拟（0 ~ 2.5 秒去程）
时间 t： 1.67 秒
P 的位置（−2 + 2t） 4/3
Q 的位置（3 − t） 4/3
P、Q 剩余间距（5 − 3t） 0（💥 相遇重合！）

🎯 解题思路

线段 AC = 5，点 P 速度为 2，所以去程 A−C 的时间为 0 < t ≤ 52。相遇就是两点走到同一个位置，即两点的坐标相等！

✍️ 标准步骤

  1. 表示坐标：去程中，点 P 表示的数为 −2 + 2t，点 Q 表示的数为 3 − t。
  2. 列方程：令 −2 + 2t = 3 − t，移项得 3t = 5，解得 t = 53。
  3. 验范围：因为 0 < 53 ≤ 52，符合题意。
第（3）②题 当点 B 将线段 PQ 分成的两部分的比为 1 : 4 时，直接写出 t 的值。
共有 3 个答案（顺序不限，如 5/7）：
作答区：
🔬 交互动画 4：双动点全程 + 1 : 4 分割比例实验室（0 ~ 5 秒）
橙线 = BP，紫线 = BQ（仅当 B 在 PQ 之间时高亮）
时间 t： 0.71 秒
✅ 情况① 成立：t = 5/7 秒时，P 在 B 左边 (−4/7)，Q 在 B 右边 (16/7)，点 B 严格在线段 PQ 之间，且 BP : BQ = 1 : 4！
当前时间 t 5/7 秒
动点 P 坐标（轨道） −4/7（去程）
动点 Q 坐标 16/7
BP 与 BQ 长度及比例 BP = 4/7，BQ = 16/7（1 : 4）

🔥 压轴题核心破题点

  1. 前提条件：“点 B(0) 将线段 PQ 分成两部分”意味着 点 B 必须在线段 PQ 之间，即 P、Q 必须一左一右分布在 0 的两侧！
  2. 有效时段：只有 0 < t < 1（P 左 Q 右）和 3 < t < 4（Q 左 P 右，此时 P 已返程，坐标为 8 − 2t）两个时段满足一左一右。
  3. 分类比例：题目未指明哪一段是 1 份，必须同时讨论 BP : BQ = 1 : 4 与 BP : BQ = 4 : 1。

✍️ 分段求解与验根

  • 时段一（0 < t < 1）：BP = 2 − 2t，BQ = 3 − t。
    • 若 BP : BQ = 1 : 4：4(2 − 2t) = 3 − t → 7t = 5 → t = 57（在 0 < t < 1 内，保留）。
    • 若 BP : BQ = 4 : 1：2 − 2t = 4(3 − t) → t = 5（不在 0 < t < 1 内，舍去）。
  • 时段二（3 < t < 4）：P 返程坐标为 8 − 2t，故 BP = 8 − 2t，BQ = t − 3。
    • 若 BP : BQ = 4 : 1：8 − 2t = 4(t − 3) → 6t = 20 → t = 103（在 3 < t < 4 内，保留）。
    • 若 BP : BQ = 1 : 4：4(8 − 2t) = t − 3 → 9t = 35 → t = 359（在 3 < t < 4 内，保留）。
  • ⚠️ 避坑说明（为什么 t = 119 是错的？）：当 t = 119 时，P = 49，Q = 169，两点全在 B(0) 右侧，B 根本不在线段 PQ 上，属于增根，必须舍去！

最终答案：t = 57 或 103 或 359。

三

解题口诀与易错避坑总结

牢记 4 条黄金口诀，数轴动点压轴题稳拿满分
口诀一

大减小

求数轴上任意两点距离，永远用右边的数 − 左边的数。特别注意：减去一个负数等于加上它的相反数，如 2 − (−8) = 10。

口诀二

左减右加

动点向右走用起点 + 速度 × 时间，向左走用起点 − 速度 × 时间，先定方向再写算式，绝不写反符号。

口诀三

往返分段

遇到折返运动（如 A−C−A），必须先算出折返时刻（本题 t = 2.5 秒），去程和返程分别写坐标表达式，切忌混用！

口诀四

增根必验

解出 t 后必须回代检验：一查是否在当前时间段内，二查是否满足几何位置（如 B 必须在线段 PQ 之间，剔除 t = 11/9 这类增根）。

两道变式巩固练习题

学以致用！先独立输入答案自测，再展开分步解析
变式题 1（中点与定向平移） 已知数轴上点 A 表示 −4，点 B 表示 6。
（1）若点 C 到 A、B 两点的距离相等（即点 C 是线段 AB 的中点），则点 C 表示的数是  ；
（2）若点 D 在点 A 的右边，且 AD = 7，则点 D 表示的数是  。
作答区：

✍️ 分步解析

  1. 求中点 C：先求总长 AB = 6 − (−4) = 10，中点将线段平分为两段，每段长 10 ÷ 2 = 5。从点 A(−4) 向右移动 5 个单位得 −4 + 5 = 1（或直接用中点公式 −4 + 62 = 1）。
  2. 求点 D：点 D 在点 A(−4) 右边 7 个单位，用“左减右加”得 −4 + 7 = 3。
变式题 2（双动点同向追及） 数轴上点 A 表示 −6，点 B 表示 4。动点 P 从点 A 出发，以每秒 3 个单位长度的速度向右运动；同时，动点 Q 从点 B 出发，以每秒 1 个单位长度的速度向右运动。问经过   秒后，点 P 追上点 Q？
作答区：

✍️ 分步解析

  1. 表示坐标：设运动时间为 t 秒。点 P 向右走，坐标为 −6 + 3t；点 Q 向右走，坐标为 4 + t。
  2. 列方程求解：“追上”即两点重合，坐标相等：−6 + 3t = 4 + t → 2t = 10 → 解得 t = 5（秒）。
  3. 算术巧解：初始距离 AB = 4 − (−6) = 10，速度差 3 − 1 = 2，追及时间 = 10 ÷ 2 = 5（秒）。
